# Nectar Boutique concept preview

A concept website for Nectar Boutique (Brandon, MB), made by Tyler Wedderburn as part of a proposal. **It is not the official Nectar Boutique website.** Booking links go to Nectar's Vagaro page and shop links go to its Shopify store.

The pages use only the section types a Shopify Online Store 2.0 theme already has (image banner, multicolumn, featured collection, collection list, collapsible content, image with text, testimonials, contact info), so the design can move into a Shopify theme.

Edit `build.py` and run `python build.py` to regenerate the HTML.
